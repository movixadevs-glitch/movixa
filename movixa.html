Perguntas Frequentes Frequently Asked Questions

O Movixa funciona sem internet? Does Movixa work offline?

Sim. O Movixa foi desenvolvido para operação local e permite utilizar suas principais funcionalidades mesmo sem conexão com a internet.

Yes. Movixa is designed for local operation and allows you to use its main features even without an internet connection.

Onde meus dados ficam armazenados? Where is my data stored?

Os dados operacionais do Movixa são armazenados localmente no dispositivo em que o aplicativo está instalado.

Movixa's operational data is stored locally on the device where the application is installed.

O Movixa utiliza armazenamento em nuvem? Does Movixa use cloud storage?

Não. O Movixa não utiliza Firebase, Firestore ou outro serviço próprio de armazenamento em nuvem para armazenar os dados operacionais do seu negócio.

No. Movixa does not use Firebase, Firestore or another proprietary cloud storage service to store your business operational data.

Meus dados são sincronizados entre dispositivos? Is my data synchronized between devices?

Não. O Movixa funciona localmente em cada dispositivo. Os dados armazenados em um dispositivo não são automaticamente enviados ou sincronizados com outro dispositivo.

No. Movixa operates locally on each device. Data stored on one device is not automatically sent to or synchronized with another device.

Posso utilizar vários usuários? Can I use multiple users?

Sim. O aplicativo permite configurar diferentes usuários e níveis de acesso de acordo com os recursos disponíveis na versão utilizada.

Yes. The application allows you to configure different users and access levels according to the features available in your version.

O Movixa faz backup dos meus dados? Does Movixa back up my data?

Como os dados são armazenados localmente, a Movixa não mantém uma cópia dos dados do seu negócio em seus servidores. Recomendamos que o usuário realize cópias de segurança quando necessário, utilizando os recursos disponíveis no aplicativo, no sistema operacional ou outros meios sob seu controle.

Because data is stored locally, Movixa does not maintain a copy of your business data on its servers. We recommend that users create backups when necessary using features available in the application, operating system or other means under their control.
