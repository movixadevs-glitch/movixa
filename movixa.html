Perguntas Frequentes Frequently Asked Questions

O Movixa funciona sem internet? Does Movixa work offline?

Sim. Você pode continuar realizando vendas e utilizando diversas funcionalidades mesmo sem conexão. Os dados são sincronizados automaticamente quando a internet estiver disponível.

Yes. You can continue selling and using most features without an internet connection. Data is synchronized automatically when connectivity returns.

Posso utilizar mais de um usuário? Can I use multiple users?

Sim. O Movixa permite múltiplos usuários com acesso ao mesmo negócio.

Yes. Multiple users can work in the same business.

Meus dados ficam seguros? Is my data secure?

Sim. Utilizamos Firebase Authentication e Cloud Firestore para proteger suas informações.

Yes. We use Firebase Authentication and Cloud Firestore to protect your information.

Existe backup automático? Is there automatic backup?

Sim. Os dados armazenados na nuvem permanecem sincronizados automaticamente.

Yes. Cloud data is automatically synchronized.
