Política de Privacidade do Movixa

Data de última atualização: 05 de junho de 2026

1. Coleta de Dados

O Movixa coleta informações essenciais para a prestação do serviço, incluindo:

  • Nome do usuário e endereço de e-mail (utilizado para autenticação).
  • Dados referentes ao seu negócio (vendas, comandas, produtos e inventário).

2. Uso dos Dados

O e-mail é utilizado exclusivamente para o login e identificação do usuário. A senha é gerenciada de forma segura pelo Firebase (Google), não sendo armazenada pelo Movixa. Os dados de negócio são utilizados apenas para o funcionamento do sistema e relatórios internos.

3. Compartilhamento de Dados

Nós não compartilhamos, vendemos ou alugamos dados de nossos usuários com terceiros. Não utilizamos seus dados para publicidade, rastreio ou qualquer outra finalidade que não seja o uso direto do aplicativo por você.

4. Segurança

Utilizamos os serviços de infraestrutura do Firebase para garantir a segurança e o armazenamento dos seus dados.

5. Contato
